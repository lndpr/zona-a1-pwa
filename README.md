# ZONA A1 - Market Intelligence Terminal

ZONA A1 adalah platform market intelligence
untuk XAUUSD dan pasar keuangan.

## Project Structure

- frontend: PWA dashboard
- worker: Cloudflare Worker API
- docs: Project documentation

## Architecture

Frontend:
GitHub Pages

Backend:
Cloudflare Workers

Database:
Cloudflare D1

Real-time:
Cloudflare Durable Objects

Trading:
MetaTrader 5 Expert Advisor

## Deployment

Frontend deployment menggunakan GitHub Actions.

Backend tetap menggunakan Cloudflare Workers.
